# Treuekarte – Thai Food Kurier

Mobile Gestaltungsvorschau einer digitalen Take-away-Treuekarte.

- Verkaufspreis CHF 140.-- für 10 Mittagsmenüs im Wert von CHF 150.--
- Mehrfachbezug vorgesehen
- Original-Logo, Kontaktlinks und Gestaltung passend zum Webshop

## Lokal ansehen

Mit Python 3 im Projektordner starten:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Danach http://127.0.0.1:8765 öffnen.

## Stand

Statische Gestaltungsvorschau. Der QR-Code ist ein Platzhalter.
Verkauf, Mitarbeiteranmeldung, Guthabenspeicherung und Entwertung sind noch nicht implementiert.
